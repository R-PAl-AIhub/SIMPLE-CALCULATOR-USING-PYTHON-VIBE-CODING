# Simple Calculator (Python + Tkinter)

A polished calculator app built with Python and Tkinter, focused on clean UI/UX and smooth interactions.

## Features

- Modern dark-theme interface with large readable display.
- Mouse + keyboard input support.
- Basic operations: addition, subtraction, multiplication, division, percentage.
- Clear (`C`), backspace (`⌫`), and sign toggle (`±`) support.
- Error handling for invalid operations.

## Run

```bash
python3 calculator.py
```

## Keyboard Shortcuts

- `0-9`, `.`, `+`, `-`, `*`, `/`, `%` for input
- `Enter` to evaluate
- `Backspace` to delete last character
- `Esc` to clear
